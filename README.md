# NIGHT DROP — сайт + админка + Telegram-бот
Все файлы заменить в репозитории (папки api и public). Переменные в Vercel те же.
Сайт: public/index.html — вверху скрипта впиши BOT и MGR (ники без @).
Админка: /admin.html. Бот: /admin.

## Напоминания (cron)
Добавь переменную CRON_SECRET (любая длинная строка). Затем на cron-job.org создай задачу:
URL: https://<сайт>/api/cron?key=<CRON_SECRET>, каждые 5 минут.

## Что нового
- Карта точек выдачи (Leaflet + CARTO dark). Координаты задаются в админке (вкладка "Время и места"), без них стандартные Hbf и Ostbahnhof берутся сами, остальные ищутся через OpenStreetMap.
- Превью ссылки: public/og.jpg + meta-теги в index.html (домен nocture-alpha.vercel.app, при смене домена поменяй в index.html). Telegram кеширует превью, обновить можно через @WebpageBot.
- Статистика: вкладка "Статистика" в админке + кнопка в боте + утренний отчёт в 9:00 (нужен cron из раздела выше).
- Приглашения: /ref 10 в боте или поле в админке. Скидки не суммируются (берётся наибольшая).
